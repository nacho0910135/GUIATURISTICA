Política de Privacidad

Esta política explica cómo Descubriendo CR trata datos personales al usar la aplicación, conforme a los principios de la Ley N.º 8968 de Costa Rica.

Datos tratados

Podemos tratar correo, nombre de usuario, nombre, foto, biografía y correo de contacto; contenido que decidís aportar, como fotos, audio, mensajes, comentarios, reseñas y ubicaciones compartidas; preferencias de viaje; estado de compras o suscripciones; ubicación precisa o aproximada únicamente cuando otorgás permiso; y el token del dispositivo necesario para entregar notificaciones.

Finalidades

Usamos estos datos para crear y proteger cuentas, prestar las funciones solicitadas, mostrar y moderar contenido comunitario, guardar preferencias, procesar acceso o compras, enviar notificaciones push y prevenir fraude o abuso. No vendemos datos personales.

Visibilidad y terceros

El perfil y el contenido que decidís publicar pueden ser visibles para otras personas. Usamos Supabase para autenticación, base de datos, funciones y almacenamiento; Expo para compilaciones y entrega de notificaciones; Google para OAuth, Google Play y facturación; Mapbox u OpenStreetMap para mapas; y OpenWeather para clima. Cada proveedor procesa los datos necesarios bajo sus propias políticas.

Conservación y seguridad

Conservamos los datos mientras la cuenta o el contenido estén activos y durante el plazo necesario para prestar el servicio, resolver disputas, prevenir abuso o cumplir obligaciones legales. Aplicamos cifrado en tránsito y controles de acceso, aunque ningún sistema garantiza seguridad absoluta.

Derechos y eliminación

Podés solicitar acceso o rectificación y revocar permisos desde el dispositivo. Para borrar permanentemente tu cuenta, credenciales, perfil y datos asociados, usá la página de eliminación de cuenta o la opción “Eliminar cuenta y datos” dentro de la app.
