# Avisos de terceros

## CR_distritos_geojson

Las geometrías administrativas de Costa Rica incluidas en `src/data/provinces.json` y `src/data/districts.json` se derivan del proyecto **CR_distritos_geojson**, distribuido bajo Apache License 2.0.

Para Descubriendo CR se normalizaron y simplificaron las geometrías provinciales y distritales para reducir el tamaño y costo de renderizado móvil. El sistema de coordenadas se conserva como WGS84 / EPSG:4326.

La licencia completa está en `licenses/CR_distritos_geojson.LICENSE.txt`.

## OpenStreetMap

El directorio de asistencia y emergencias incluye instituciones de Costa Rica identificadas en OpenStreetMap y consultadas mediante el conjunto de datos OSM Planet de QLever. Estos datos se distribuyen bajo la licencia Open Database License 1.0 (ODbL).
