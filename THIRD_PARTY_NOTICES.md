# Avisos de terceros

## CR_distritos_geojson

Las geometrías administrativas de Costa Rica incluidas en `src/data/provinces.json` se derivan del proyecto **CR_distritos_geojson**, distribuido bajo Apache License 2.0.

Para Descubriendo CR se modificaron los archivos provinciales: se normalizaron sus anillos como polígonos independientes y se simplificaron las coordenadas para reducir el tamaño y costo de renderizado móvil. El sistema de coordenadas se conserva como WGS84 / EPSG:4326.

La licencia completa está en `licenses/CR_distritos_geojson.LICENSE.txt`.
